## 服务详细设计

### 1. 前端服务 (ChatGPT-Next-Web)
**功能**：
- 类ChatGPT的聊天界面
- 支持Markdown渲染
- 会话历史管理
- 用户权限控制

**特性**：
- 响应式设计，支持PC和移动端
- 支持文件上传
- 实时打字机效果
- 多主题切换

### 2. API网关 (Nginx)
**功能**：
- 请求路由和负载均衡
- HTTPS终止
- 静态文件服务
- 访问日志记录

**配置重点**：
- 反向代理到后端服务
- WebSocket支持（实时聊天）
- 文件上传大小限制
- 访问频率限制

### 3. 后端服务架构

#### 3.1 对话管理服务
```python
# 主要功能
- 会话管理和上下文维护
- 用户输入预处理
- 响应流式输出
- 聊天历史存储
```

#### 3.2 知识库服务 (RAG)
```python
# 检索增强生成流程
1. 接收用户问题
2. 问题向量化
3. 向量相似度搜索
4. 上下文重排序
5. 构建增强Prompt
6. 调用LLM生成回答
```

#### 3.3 文档处理服务
```python
# 文档处理流水线
1. 文档上传和格式检测
2. 文本提取和清洗
3. 文档分块和向量化
4. 向量存储和索引
5. 元数据管理
```

#### 3.4 模型推理服务 (vLLM)
```python
# vLLM配置
- 支持Qwen2.5模型
- 异步批处理
- 动态批处理优化
- GPU内存管理
```

## Docker容器化方案

### 容器架构
```
Docker Host
├── nginx-gateway          # 反向代理网关
├── chatgpt-next-web       # 前端UI
├── chat-api               # 对话管理API
├── rag-service            # 知识库检索服务
├── doc-processor          # 文档处理服务
├── vllm-inference         # 模型推理服务
├── chromadb               # 向量数据库
├── postgresql             # 关系数据库
├── minio                  # 对象存储
├── redis                  # 缓存服务
└── prometheus             # 监控服务
```

### 网络设计
```yaml
networks:
  frontend:  # 前端网络
  backend:   # 后端服务网络
  storage:   # 存储网络
```
