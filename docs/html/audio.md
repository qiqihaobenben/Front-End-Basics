# 音频相关

音频的编码格式和源码格式是数字音频技术的基础，它们共同决定了音频的质量、文件大小以及适用场景。下面这个表格汇总了常见的音频编码格式及其关键特性，可以帮助你快速了解概况。

| 格式名称       | 类型              | 主要特点                                                                                             | 常见文件扩展名            |
| :------------- | :---------------- | :--------------------------------------------------------------------------------------------------- | :------------------------ |
| **PCM**        | 未压缩            | 最原始的音频数据格式，音质保真度最高，但体积庞大。是其他编码的源头。                                 | .wav, .aiff, .cda (CD-DA) |
| **WAV**        | 通常为 PCM 的容器 | 微软开发，常用于 Windows 平台。其文件内部通常封装了 PCM 编码的音频数据，并包含采样率、位深度等信息。 | .wav                      |
| **AIFF**       | 通常为 PCM 的容器 | 苹果开发，常用于 Mac 平台。与 WAV 类似，也是一种常见的封装 PCM 数据的容器格式。                      | .aiff, .aif               |
| **FLAC**       | 无损压缩          | 压缩比约为 2:1，解压后可完全还原为原始 PCM 数据，音质无损失。                                        | .flac                     |
| **APE**        | 无损压缩          | 压缩率较高，但编解码复杂度也高，硬件支持不如 FLAC 广泛。                                             | .ape                      |
| **ALAC**       | 无损压缩          | 苹果开发的无损压缩格式。                                                                             | .m4a                      |
| **MP3**        | 有损压缩          | 利用人耳听觉心理声学模型去除“不重要的”声音信息，大幅减小体积。在 128-320kbps 码率下平衡音质与大小。  | .mp3                      |
| **AAC**        | 有损压缩          | MP3 的继任者，在相同码率下通常能提供比 MP3 更好的音质，支持多声道。是 iPhone、YouTube 等的标准格式。 | .aac, .m4a, .mp4          |
| **WMA**        | 有损/无损         | 微软开发，包含有损压缩的 WMA（类似 MP3）和无损压缩的 WMA Lossless。                                  | .wma                      |
| **Ogg Vorbis** | 有损压缩          | 开放且免专利的格式，音质优于同码率的 MP3。                                                           | .ogg                      |

### 理解音频的“源码”

我们通常所说的音频“源码”或“原始格式”，指的是未经任何压缩或仅被封装格式包裹的**PCM（脉冲编码调制）数据**。

1.  **PCM 是数字音频的起点**：它是将模拟声音信号（声波）直接通过**采样、量化、编码**三个步骤转换得到的数字信号。你可以把它想象成用极高的精度，对声音波形进行“拍照”并记录下每个点的数值。
2.  **关键参数**：PCM 数据的质量由三个关键参数决定：
    - **采样率**：每秒对声音采样的次数（单位：Hz）。采样率越高，能记录的频率范围越广。CD 品质的采样率为 44.1kHz，即每秒采样 44100 次。
    - **位深度**：每个采样点用多少位二进制数来记录其振幅（精度）。位深度越高，动态范围越广，声音的细节越丰富。CD 标准为 16 位。
    - **声道数**：单声道为 1，立体声为 2，环绕声则有 5.1、7.1 等。
3.  **常见的 PCM 容器格式**：WAV 和 AIFF 文件通常就是直接存储 PCM 数据流，并在文件开头加上一个描述音频参数（如采样率、位深度）的头部信息。因此，它们常被视为最“原始”的音频文件格式。

### 如何选择适合的音频格式

了解不同格式的特性后，你可以根据具体需求做出选择：

- **追求极致音质或进行专业音频编辑**：首选**PCM（WAV/AIFF）** 或**无损压缩格式（FLAC/APE）**，它们能最大程度保留原始音质。
- **日常聆听与存储，平衡音质与文件大小**：现代有损压缩格式如**AAC**（256kbps 及以上）或**Ogg Vorbis**是非常好的选择，它们在保证良好听感的同时显著节省空间。
- **广泛兼容性，确保在任何设备上都能播放**：**MP3**尽管技术较老，但其无处不在的兼容性仍是分享音乐时的稳妥选择。
