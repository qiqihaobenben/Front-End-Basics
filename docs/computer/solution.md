# 装机方案

## 使用场景

多语言开发+Docker，偶尔打 3A。核心诉求是：**多核（并发编译/容器）+ 充足内存 + 高速 SSD + 中高端显卡**。下面是两套可靠配置，再附一个更“偏游戏”的替代 CPU 选项。

---

## 方案 A（推荐）：**Dev & AAA 平衡工作站**（AMD 平台）

**用途**：重度开发/多容器/多语言编译 + 1440p/4K 3A 游戏
**目标**：安静、稳定、可升级、功耗合理

- **CPU**Intel **Core Ultra 7 265K** （16 核心，能效比优异，AI NPU） 散片 1900 元
- **散热器**：高端塔式（如 6 热管 120/140 风扇）或 240 一体水冷（静音优先）
- **主板**：Z790 / B760 高端款（DDR5，至少 2–3 个 M.2 插槽，带 2.5G 网口 + Wi-Fi 6E）大约 1400 元
- **内存**：**64GB（2×32GB）DDR5-6400**（EXPO 一键到位；给 Java/Node/Docker 足量内存）单价 800 元，总共大约 1600 元
- **显卡**：**GeForce RTX 5070 12G**（兼顾常见 CUDA 场景）大约 4400 元
- **系统盘**：**2TB NVMe Gen4**（PCIe 4.0，读写 7GB/s 级别；装系统/IDE/常用容器层）单价大约 900 元
- **项目/素材盘**：**2TB NVMe Gen4**（把 Docker 镜像层/工作目录与系统盘分离，IO 更稳）单价大约 900 元
- **机箱**：前面网孔、原生 3–4 风扇位，走线顺滑（利于静音和散热）
- **电源**：**850W 80+ Gold**（留升级余量，半模组/全模组都行）大约 500 元
- **网卡/无线**：主板集成 **2.5G 有线 + Wi-Fi 6E** 足够
- **系统**：Windows 11 Pro + WSL2 / 或 Linux 主力 + Windows 虚拟机均可

**为什么这样配？**

- 12 核 + 64GB 对 **多容器/多语言并发** 特别友好；两块 NVMe 让 Docker 镜像层与工作目录分盘，**磁盘竞争大幅减少**。
- 4070 Ti Super 在 1440p 高画质/光追 + DLSS 下体验稳，兼顾 CUDA 生态。
- 850W 为未来升级（更高端显卡/更多 SSD）留足余量。

## 细节与小技巧（强烈建议打开/设置）

- **BIOS**：开 **SVM/VT-x/VT-d/IOMMU**（虚拟化直通）、开启内存 EXPO/XMP；更新到稳定版本。
- **Docker**：把 `data-root` 指向二块 NVMe（工程盘）；给 Docker Desktop/WSL2 合理限制 CPU/内存（例如 8–12 vCPU、16–24GB）。
- **包管理与缓存**：Node/Gradle/Maven/Python 的 cache 指向工程盘 NVMe，减少编译时间。
- **散热与噪音**：机箱前进后出，风扇曲线在 40–60℃ 之间做个平滑段，日常基本听不见。
- **显示器建议**：**27–32" 1440p/165Hz** 是开发+游戏的甜点；若 4K，保证显卡层级 ≥ 4080S 或降低特效换帧。

## 如果你偏好 Intel 平台（可替换方案 A 的“同档位”）

- **CPU**：**Core i7-14700K** 大约 2200 元
- **主板**：Z790（留更多 PCIe/M.2 位）大约 1300 元
- **内存**：64GB DDR5-6400（按主板 QVL 走）单价 800 元，总共大约 1600 元
- **散热**：240–360 一体水冷（14700K 负载时热设计冗余要足）
- 其余与方案 A 相同

> 优点是 **Quick Sync** 做转码剪辑很爽；缺点是**发热与功耗**会更高，机箱与散热一定要扎实。
